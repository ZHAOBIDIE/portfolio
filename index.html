Reflection

week 2

This is the first time for me to create a website. We learned how to use both CampusPress and Github to create websites. With CampusPress, we could use a variety of templates. These templates are really helpful. Another way to create a website is using code. We could use VS Code to manage the code, create both CSS and HTML files, uploading them to Github. In this workshop, I learned the difference between CSS and HTML format files, and got some additional resourses of creating websites. I hope I can do better.

week 3

This week, we began to learn web scraping. I heard web scraping long time ago, but I did not know how to do. It is very useful in data collecting. In this workshop, we tried to scrape films from BBC website using Webscraper. I did something wrong at the beginning of the class. Finally, it worked well. As a tool, it can help me get a variety of data directly from a website, downloading a editable table. We also have other ways to scrape the web, using Python programming language.

week 4

This week, we started a new workshop-data and data analysis. Firstly, I learned the definition of data, data sets, and data collection. These terms are topics of our workshop. Our group chose Scenario 1 to collect and analysis data. Our question is "How do university students utilize Generative AI to read and comprehend academic literature, and what practical challenges or ethical risks". We have five variables, purpose of using AI, tools, faced challenge, sentiment, and the amount of comments. I scraped posts on Reddit to find students' purpose. In the table which I downloaded from Reddit, I saw more students using AI for methodology than others.

week 5

This workshop builds upon the previous one. We learned 3 key words, dataset, variables, and chart types at the beginning. Then we began sharing our observations in group and in class. I was shocked by the number of negative reviews. I thought there were a lot of students using AI, most of them won't be so negative. After sharing our observations, we learned data visualisation. Dataset cannot be displayed directly without visualisation. If people see a large scale data, they may not know exactly what they see. We can use different chart types to visualize different kinds of dataset. When I was still working, we usually use charts to let the partners understand our design.
